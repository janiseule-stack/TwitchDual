# Regal von nahe – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Regal-Ansicht zeigt jeweils ein Fach formatfüllend (Fach für Fach). Beim Hover steht der Name groß darüber. Ein Klick zeigt die Hülle mit der Platte, die heraus schaut und sich dreht, daneben eine Tafel mit Vorschaubild, dahinter die großen Namen. Die Rückseite ist quadratisch und trägt eine Trackliste. Beim Suchen fährt die Kamera zum Treffer.

**Architecture:** Die Geometrie kommt als reine, getestete Funktionen nach `renderer/lib/raum.js`:
- Faktor je Fach
- Fachfahrt
- Klick-Maße
- nächstes Fach
- Lage des Hover-Namens
- Zeilen der großen Namen

`renderer/video/home-raum-dom.js` legt die Regal-Ebene je Fach aus und baut die Karte neu. `renderer/video/home.js` verdrahtet Tasten, Suche und Ansichten.

Die Fachfahrt ist eine FLIP-Fahrt auf einer **inneren** Ebene `t.regalInnen` (umschließt Bild- und Textschicht, nicht die Karte), `transform-origin: 0 0`. Sie nutzt `fahrtNr`/`fahrtSchritt`/`stoppeFahrt` mit.

**Tech Stack:** Electron-Renderer, Vanilla JS (UMD/IIFE wie bestehend), CSS, `node --test` (`npm test`).

**Spec:** `docs/superpowers/specs/2026-11-13-regal-nah-design.md`. Optik-Vorlage (kein App-Code): `renderer/themes/cozy/entwuerfe/mockup-regal-nah/index.html`, Fotos `_ANSCHAUEN/81-…`, `82-…`, `83-…`. Prüfung des Plans: zwei Goldfisch-Helfer (13.11.2026).
