# Regal von nahe – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Regal-Ansicht zeigt ein Fach formatfüllend (Fach für Fach). Beim Hover steht der Name groß darüber. Eine angeklickte Platte erscheint als Hülle mit herausschauender Platte, daneben eine Tafel mit Vorschaubild, dahinter die großen Namen. Die Rückseite ist quadratisch und trägt eine Trackliste.

**Architecture:** Die Geometrie (Faktor je Fach, Kamerafahrt zwischen den Fächern, Maße der Klick-Ansicht) kommt als reine Funktionen in `renderer/lib/raum.js`, mit Unit-Tests. `renderer/video/home-raum-dom.js` legt die Regal-Ebene je Fach aus und baut die Karte neu. `renderer/video/home.js` verdrahtet Tasten und Ansichten. Die Fachfahrt ist eine FLIP-Fahrt: Die ganze Regal-Ebene (Bild und Text) wird per transform erst auf die Gesamtansicht gezogen, dann neu ausgelegt und aus der Gesamtansicht ins neue Fach gezoomt. So bleibt nach der Fehlerbuch-Lehre der Fixpunkt im Gegenstand.

**Tech Stack:** Electron-Renderer, Vanilla JS (UMD/IIFE wie bestehend), CSS, `node --test` (`npm test`).

**Spec:** `docs/superpowers/specs/2026-11-13-regal-nah-design.md` (baut auf `2026-11-11-regal-neu-design.md` auf). Vorschau: `renderer/themes/cozy/entwuerfe/mockup-regal-nah/index.html` (nur zum Nachsehen der Optik, kein App-Code), Fotos `renderer/themes/cozy/entwuerfe/_ANSCHAUEN/81-…`, `82-…`, `83-…`.
