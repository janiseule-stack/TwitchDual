# Home als CD-Bühne, Runde 2 – Implementation Plan

> Ausführung: inline (executing-plans), schlank auf Janis' Wunsch; Goldfisch-Prüfung am Schluss.

**Goal:** Janis' sieben Änderungswünsche umsetzen (Spec `docs/superpowers/specs/2026-11-09-home-cd-v2-design.md`).
**Architecture:** Neue reine Logik in `renderer/lib/home-buehne.js` (Ständer-Einträge, Laufwerk-Ablauf) und `home-punkte.js` (Generation), getestet unter Node; Darstellung in `renderer/video/home-buehne-dom.js`/`home.css`, Steuerung in `home.js`.
**Spec:** `docs/superpowers/specs/2026-11-09-home-cd-v2-design.md`

## Global Constraints
- Wie Plan Runde 1: kein `backdrop-filter`/`mix-blend-mode`, Dauer-Animationen nur transform/opacity, Farben aus Theme-Variablen (außer CD-Silber/Regenbogen, Lade-Terminal), keine neuen kollidierenden globalen Namen, Kommentare ohne Umlaute, Dateien nur per Edit/Write, cdp-eval außen `"` innen `'` ohne `$`, keine Screenshots der App, Janis schaut an.
- Profilbild 300 px (gemessen 09.11.2026: `profileImageURL(width:300)` liefert `…-300x300.png`).
- Laufwerk-Ablauf: Mindestdauer 1500 ms; `submitLoad` startet sofort; Home schließt erst, wenn beides fertig.
- Namen: Laufzeiten ×3 (180/225/270/210/255 s); Mittelzeile direkt hinter der CD.

## Tasks
1. **Profilbild 300 px** – `src/twitch-browse.js` `LIVE_QUERY`/`LIVE_BATCH_QUERY` `profileImageURL(width:300)`; Test in `test/twitch-browse.test.js` (Query enthält `width:300`).
2. **Logik** (TDD, `test/home-buehne.test.js`, `test/home-punkte.test.js`):
   - `HomeBuehne.staenderEintraege({ live, offlineFavoriten, offlineTreffer, twitchTreffer, suche })` → `[{kanal, art:'live'|'offline'|'twitch'}]` (ohne Suche: live + offline Favoriten; mit Suche: live-Treffer + offline-Treffer + twitch-Treffer, ohne Doppelte).
   - `HomeBuehne.createLaufwerk({ mindestMs = 1500, jetzt, setzeTimer, loescheTimer })` → `{ start(beiFertig), geladen(ok), abbrechen(), laeuft }`: `beiFertig(ok)` erst, wenn Mindestzeit vorbei **und** `geladen` gemeldet; `geladen(false)` beendet sofort mit `false`; `abbrechen()` ohne Rückruf.
   - `HomePunkte`: Generationszähler, `leeren()` erhöht ihn, Antworten älterer Generation werden verworfen.
3. **Hülle + Cover + CD + Ständer** (DOM/CSS): Booklet-Cover (Profilbild 300 px als Foto, Titel = Name, Untertitel = Spiel, Hover blendet Stream-Vorschau 16:9 ein), Jewel-Case-Look (Scharnier, Plastik-Glanz), realistische CD (Rillen, Silber, Regenbogen nur auf dem Ring) mit Profilbild-Label und Flip beim Herausfahren, Theme-Motive + `cd-motiv.svg` entfernen, `#home-regal` + Nachbarn durch `#home-staender` (schräge Alben, Live-Punkt, Offline grau, Auswahl hervorgehoben, in Sicht scrollen, Mausrad blättert) ersetzen.
4. **VOD-Rückseite**: gedrehte Hülle wird größer; Inlay mit großem Titel, 2×2 VODs mit großem Vorschaubild (Länge, Nr., Titel, Datum, Aufrufe), Seiten ‹ › (je 4, `channelVods` mit bis zu 24).
5. **Laufwerk**: Overlay über der Bühne (Schublade aus → CD rein → zu, LED orange → Terminal „Lese Disc … LOGIN.ISO“ + Balken), gesteuert von `createLaufwerk`; Effekte „aus“ ohne Animation.
6. **Namen + Restpunkte**: Laufzeiten ×3; Mittelzeile hinter der CD, Akzentfarbe + Leuchten, Deckkraft ~doppelt; `homeNamenNeu` nur bei Theme-ID/Schrift-Wechsel (nicht bei Vorschau).
7. **Abnahme**: `npm test`; DOM-Prüfungen per cdp-eval; Leistung (≤ 2 Frames > 33 ms / 10 s, Sakura/viel, Stream); dann Goldfisch-Prüfung des Ergebnisses (Janis' Wunsch), Janis schaut an.
