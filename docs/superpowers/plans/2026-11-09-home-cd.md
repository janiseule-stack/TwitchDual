# Home als CD-Bühne Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home im Video-Fenster wird zur CD-Bühne: drehende CD mit Vorschaubild, Riesen-Namen vor der Theme-Welt, Mausrad-Blättern, Suche mit fester Enter-Reihenfolge, Regal mit Offline-Favoriten, VOD-Rückseite, Kanalpunkte-Sticker.

**Architecture:** Daten bleiben (`home-kanaele`, `HomeListe.abschnitte`, `kanal-suche`, `channel-vods`). Reine Logik in DOM-freien UMD-Modulen (`home-liste.js` erweitert, neu `home-buehne.js`, `home-punkte.js`), unter Node getestet. Darstellung in `renderer/video/home-buehne-dom.js` (IIFE, nur `HomeBuehneDom` global), `home.js` bleibt Steuerung. Ein neuer IPC-Aufruf `home-punkte`.

**Tech Stack:** Electron 33, Vanilla-JS (normale `<script>`-Dateien teilen einen globalen Bereich, kein Bundler), CSS, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-09-home-cd-design.md` (Prüfberichte Spec + Plan: `docs/superpowers/specs/egm-home-cd/`)

## Global Constraints

- Branch `feat/home-cd`. Nach jedem Task `npm test` grün, dann committen; Commit-Nachricht endet mit `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Auf Home **kein `backdrop-filter` und kein `mix-blend-mode`**; Dauer-Animationen nur `transform`/`opacity`.
- `prefers-reduced-motion` bewusst ignorieren – keine Media-Query dafür.
- Effekte-Stufen `aus`, `wenig`, `normal`, `viel` (`renderer/lib/themes.js:81`). Auf Home: `aus` → Namen stehen, CD dreht nicht; **alle anderen Stufen gleich** (volle Bühnen-Animation). CD-Wechsel und Hülle-Drehen sind Bedienung und immer animiert.
- Keine Kanalnamen aus Janis' Beispielen in Code/Tests/Commits; Testdaten `kanal_a`, `kanal_b`, …
- Kommentare deutsch ohne Umlaute wie im Bestand.
- Neue Renderer-Dateien nie mit `const`/`let`/`function` auf oberster Ebene außer dem einen exportierten Namen (Kollision mit `video.js`/`home.js`, die viele Namen global anlegen): UMD-Rahmen wie `renderer/lib/chat-ui.js:5-10` bzw. IIFE.
- Anschauen macht Janis. Eigene Prüfungen nur per `npm test` und DOM-Abfragen über `tools/cdp-eval.js`, keine Screenshots, kein Neuladen der Seiten per CDP. App-Start für Prüfungen in Git-Bash, im Hintergrund: `npx electron . --remote-debugging-port=9333 --enable-logging 2> "$TEMP/td-log.txt"` (Bash-Werkzeug mit Hintergrund-Ausführung).
- Version wird **nicht** erhöht, kein Release (Releases werden gebündelt, erst auf Janis' Ansage).
- **Farben nie fest weiß/schwarz:** Sakura, Koi und Wald sind helle Themes (`data-hell="1"`). Alle Home-Farben aus `var(--text)` ableiten, z. B. `color-mix(in srgb, var(--text) 10%, transparent)`.
- Größen über Container-Abfragen: `#home { container-type: size; }`, Bedingungen `@container (max-width: 900px)` / `(max-height: 520px)`, Längen in `cqw`/`cqh`.
- Feste Werte: 6 Namenszeilen (Mittelzeile = Zeile 3), < 520 px Home-Höhe → 3 Zeilen (2, 3, 4); höchstens 20 Namen; Tracklist 8 VODs (9 laden); Vorschau `-640x360`; Punkte nach 400 ms Stillstand, Speicher 5 min; Enter wartet höchstens 1500 ms auf `kanal-suche`; < 900 px Home-Breite → Info-Block unter die Hülle.

## Begriffe im Plan

- **Kanal**: Objekt aus `home-kanaele`/`mapLiveUser`: `{ login, displayName, avatar, live, title, game, viewers, viewersLabel, thumb, start, favorit, gefolgt, verifiziert?, error? }` (`avatar` = Profilbild-URL; `start` neu aus Task 1).
- **Reihe**: Liste der Live-CDs = `[...favoriten, ...live]` aus `HomeListe.abschnitte({ kanaele, nadel: '' })` – **immer ungefiltert**.
- **Offline-Markierung**: vordere Live-CD, die beim Aktualisieren nicht mehr live (oder nicht mehr in der Reihe) ist → `aktuelle().offline === true`.
- **Offline-Ansicht**: per Klick auf einen Regal-Rücken gezeigter Offline-Kanal; Zustand `offlineAnsicht` in `home.js`, nicht in `HomeBuehne`.
- **`punkteLogin`**: vorhandene Variable in `home.js:450` (Kanalpunkte-Teil der Anmeldung da).

## Review Focus

1. **Schnell eigenen/fremden Login + Enter, während ein eigener Live-Kanal mit längerem Login vorne steht** → lädt den getippten Login (Tests Task 2, Prüfung Task 9).
2. **60-s-Aktualisierung, vordere CD geht offline, Maus auf ▶** → CD bleibt, ▶ aus, kein Tausch (Test Task 3).
3. **Schnelles Blättern bei angemeldetem Web-Login** → höchstens eine Punkte-Abfrage pro Stillstand; beim Wechsel ist der alte Sticker sofort weg (Tests Task 4, Regel Task 7).
4. **Abgelaufener oder gesperrter Web-Token** → nach der ersten solchen Antwort keine Abfragen bis zum nächsten Öffnen von Home (Tests Task 4 + 5).
5. **Frischer Start ohne Live-Kanäle und ohne Anmeldung** → Hülle „Gerade spielt niemand“ bzw. „Noch keine Kanäle …“, Anmelde-Leiste sichtbar, keine Fehler im Log (Task 6 Step 5).
